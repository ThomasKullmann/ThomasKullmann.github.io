# ThomasKullmann.github.io

Öffentliche Seiten zu GRIND, veröffentlicht mit GitHub Pages:

- `grind/privacy.html`: Datenschutzerklärung und Impressum der App, erreichbar unter <https://thomaskullmann.github.io/grind/privacy.html>. Diese Adresse steht in der Play Console und in App Store Connect, sie sollte sich nicht ändern.

Die Seite entsteht im Spiel-Repository: Angaben in `app/app.config.json` eintragen, `node tools/bundle.mjs --app` ausführen und `dist/app/privacy.html` hierher nach `grind/privacy.html` kopieren.
